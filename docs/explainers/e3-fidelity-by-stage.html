Experiment E3 on the custom set's validation split. Each translator trains in two arms: a control with the detection weight at 0, and a loop that raises it 0, 1, 2, 3 over four stages. Loop and control share a seed, so every difference is paired: pix2pix has 6 seed pairs, pix2pix-turbo has 3. PSNR is new on this page; LPIPS and mAP50 are re-read from the same run files and match the published records.

  • pix2pix: PSNR points the same way as LPIPS. The loop arm ends a little further from the real visible frames. The LPIPS interval excludes zero, but the PSNR interval is wide and crosses it.
  • pix2pix-turbo: the loop arm leads on PSNR and LPIPS at every stage, including stage 0, where the detector has no weight yet. Its PSNR lead shrinks from stage 0 to stage 3, so the stage-3 gap is mostly a seed draw carried forward, not something the loop added.
  • Both: PSNR rewards blur, so a flat PSNR does not show that fine structure survived. That is the job of the faithfulness check (the false-object, missed-object and consistency rates). pix2pix passed all three. Turbo failed on the false-object rate: its 3-seed interval reaches +0.054, past the 0.0315 margin. So turbo's good PSNR and LPIPS here do not clear it.

How these numbers were made
  • Runs. pix2pix: runs/e3b-{control,loop}-s0…s5, at the detection-gradient scale 0.15, 400 translator epochs per run. pix2pix-turbo: runs/e3t-{control,loop}-s{0,1,3}, cut to three seeds after out-of-memory crashes. Nothing was retrained for this page.
  • Read. t2o aggregate on the server on 2026-11-14, at commit e11380b. It read each run's metrics.json, which the loop writes after every stage. PSNR had been saved there all along; it had just never been asked for.
  • PSNR. Scored on the exported 8-bit PNGs against the real visible frames, with torchmetrics at data range 1.0. The squared error is pooled over the whole split, then turned into one PSNR. It is not an average of per-image PSNRs.
  • LPIPS uses the AlexNet backbone. mAP50 is zero-shot: the fixed reference detector scores the translated images with no fine-tuning.
  • Tests. p is an exact two-sided sign-flip test over all 2ⁿ sign assignments. The CI is a 10,000-resample bootstrap. With 3 pairs, the bootstrap interval is little more than the range of the three differences, so read turbo's intervals as "do all three seeds agree", not as a precise range.
  • Sources. The three files behind this page are the two server logs and their CSVs, kept in the repo's logs/ folder as 2026-11-14-no-task-e3{b,t}-psnr*. Their values are embedded in this file; nothing is fetched.
